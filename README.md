# Vitamin VVV

Landing page and style test for Vitamin VVV, a designer lifestyle brand built around rainwear.
Live at https://vikiimyd.github.io/vitamin-vvv/

- `index.html`: the page. Visitors rank six looks, pick between two versions of their favourite, and can join the waitlist.
- `img/`: the 24 look images. `fonts/`: Hanken Grotesk (SIL Open Font License, see `fonts/OFL.txt`).
- `share.jpg`: the link-preview image.

Links: the plain address is open to anyone. Add `#interview` for the interview flow. Add `#preview` (or `#interview-preview`) to see the hidden preview notes; answers sent from a preview are marked "Test".
